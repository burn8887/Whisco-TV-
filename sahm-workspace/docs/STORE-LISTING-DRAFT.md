## Name
Sahm Demo

## Short description
Explore fictional Bahrain road alerts in a native driving-awareness demo.

## Description / TestFlight beta description
Sahm Demo previews a road-awareness experience designed for Bahrain and the Gulf. Run a simulated drive without GPS permission, explore heading-aware fictional alerts, see section-average calculations and keep local trip summaries.

Optional device GPS testing requires precise location and is started explicitly while safely parked. It may continue in the background until you end the test, subject to OS restrictions. Voice prompts temporarily reduce other audio where supported. Report drafts stay on your device and are not published.

All included camera, hazard and section data is fictional. Do not use this demonstration for road-safety decisions, ticket avoidance or navigation. Always follow actual signs and road rules. Only Bahrain has a bundled fictional pack; no country has verified coverage. Car-display/watch integrations, vehicle automation, subscriptions and internal navigation are not enabled.

## What to Test
1. Run the 75-second simulation without granting location access.
2. Observe sample speed, section average and demo alert; end the session and find its summary in My trips.
3. Save/delete a community draft while no session is active.
4. Review Settings → Privacy notice; change voice preference and country while idle.
5. Only when safely parked, start/stop a device GPS test; verify permission denial, background indicator and stopping behavior. Do not rely on fictional alerts on the road.

## Review notes
No login, subscription or purchase is required. Simulation is foreground-only and ends when the app is backgrounded. Device GPS testing is separate and explicit. Location and audio background modes support an active GPS test and short spoken alerts, not hidden tracking. Android uses an ongoing location foreground-service notification. If location is denied, simulation remains available. SQLite alert data is bundled; no live feed or user-report submission endpoint is connected.
